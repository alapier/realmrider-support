Realmrider Cookie Policy

Effective 3 November 2026 · Version 1.0 · Support · Privacy · Terms · Refunds

Cookies

Realmrider sets no cookies. The game's code never reads or writes a cookie, and there is no cookie consent banner because there is nothing to consent to.

Storage the game does use

  • Local storage (essential). One entry, realmrider.save.v1.1, holding your progress, armory choices and settings so the game remembers them between sessions. Without it the game would start from scratch every time. It is never sent anywhere.
  • Offline cache (essential, web build only). A browser cache of the game's own files and fonts so the game opens offline and updates quickly.

Neither is used to identify you, measure you or show you anything. Both are "strictly necessary" under the EU ePrivacy rules and need no consent.

Third parties

The game loads fonts from Google Fonts. Google states that the Google Fonts API does not set cookies: see Google Fonts privacy notes. The App Store and Google Play purchase screens are Apple's and Google's own and are covered by their policies.

Clearing it

In the game: Settings › Support and privacy › Delete my data (versions released after 2 November 2026); in older versions, delete the app. In a browser: clear site data for the game's address. Deleting the app removes everything.
